# BBTV 0.2.0

- 优化安装速度，改善安装进度长时间停留在“正在安装”的问题。
- 修复模板视频对比预览暂停时显示模型标识的问题，改为显示真实原片封面。
- 模板素材支持分段下载与断点续传，复用已有代理配置；关闭模板库后继续处理，网络异常时可使用网盘下载和手动导入。
- 模板下载进度采用紧凑横排，新模板标记加大动态幅度并增加描边。
- 模板素材支持 ZIP、已解压文件夹及多层目录导入，自动识别有效模板包。
- 使用模板时保留参考素材和预设参数，结果节点留待用户生成。
- 评论与标注编辑优先使用已安装的 Qwen Image 2.1 Turbo；未配置 Turbo 时使用标准版。
- 改进 OpenCode Go 地址识别及会话要求提示，区分模型目录读取与实际创作调用。
- 模板库可独立更新，支持分类排序、作者署名链接及新模板预告。
- 增强 MCP 模板选择、状态查询与工具调用，更新配套技能包和模板操作指引。
- 完善 Gemini 与 Nano Banana 的图片编辑、比例和清晰度适配；复制比例与图片复刻可匹配当前接口支持的邻近比例。
- 新增 H3 姿势迁移 LoRA 与双参考模板，可替换姿势和主体图片，提示词保持可编辑。
- 新增“漫剧人物入景·纸鹤起飞”模板：人物与场景双参考入景，再生成8秒纸鹤起飞视频，参考素材与生成参数可自行替换。
- 修复 H3 社区分段采样流程启动时的参数传递问题。
- 更新批量图片下载弹窗，保留逐张下载和 ZIP 压缩包选项，移除画布左下角分组模板入口。
- 模板视频可自动循环播放，资源受限时改为悬停播放，移除预览上的播放与暂停覆盖按钮。
- 加宽打光面板，亮度数值与百分比完整同排，调节箭头在悬停或聚焦时显示。
- 云端图片不再显示本地采样步数，生成信息可查看实际连接来源和请求状态。
- 已受理的云端图片任务在断线后继续查询；无法确认时明确显示状态未确认，避免自动重复提交。
- 素材与目录使用本地缓存，资源未变化时直接复用，减少重复加载与下载。
- 修复文生图连续生成时错误连接上一张结果的问题，首张与“+1”结果从同一文本来源独立分支。
- 多选图片沿用单图输入框和完整参数面板，可切换“合并参考”与“逐图处理”，支持本地与云端模型，结果自动避开已有节点。
- 提示词中的明确比例与清晰度默认自动匹配，保留用户手动选择；可在设置中开启手动读取，预览后应用。
- 切换图片接口后重试使用当前选择，避免恢复为上一次生成的旧接口。
- 模型原站下载失败时持续显示备用网盘提示，保留具体错误；尚无网盘的文件明确说明，配置完成后可直接保存并重启软件。
- 修复卸载模型窗口偏离屏幕中心的问题，选择页、清单和确认窗口随窗口大小保持居中。
- 改善本地语言模型的资源判断，修复部分本可运行的任务被提前拦截，以及组件存在却无法使用的问题。
- 完善 Ollama 模型清单与配套文件导入、完整依赖检查和模型列表刷新，改善图片反推模型识别。
- 新增 Sand AI MAGI-2 官方接口适配，完善火山视频素材与参数兼容。
- 修复视频任务查询或成品读取中断后的恢复问题，避免重复提交已受理任务。
- 修复相关 Bug。

已有项目、媒体、模型与接口设置保留。

安装器大小 209,694,584 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。
