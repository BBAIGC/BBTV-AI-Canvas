# BBTV 0.1.56

- 更新首次配置引导，统一标题与居中布局，使用深色背景、透明滚动条和缓慢流动的渐变按钮；已安装用户可随时返回画布。
- 配置引导使用系统原生最大化与还原，保留合适的窗口尺寸，改善切换时的闪动。
- 恢复拖入引擎与模型时覆盖整个窗口的磨砂提示；首次确认保存位置后自动继续导入原文件，并显示进度。
- 重新打开引导时保留已保存的模型共用方式，未修改直接继续不会重写设置；共用模型文件夹不再切换推理引擎。
- 目录选择从当前路径打开，引擎保存位置自动补齐 engine 文件夹，已有引擎目录不再重复套层。
- 修复参考图片的显示比例随新结果尺寸改变，以及单张复制后重新生成时误带原分组的问题。

- 人脸替换按实际已处理帧更新进度，模型检测失败后可在原地重试。
- 已保存的云端接口重新获取模型后，文字节点同步更新可用模型。
- 项目主页支持在本机正式版与内测版之间拖入和批量传送项目，随项目带上本地素材。
- 模型和引擎迁移完成后，重启可清理已校验的旧文件；已接入的外部 ComfyUI 继续原位使用。
- 修复托盘与设置中重新启动时长时间等待或无法重新打开的问题。
- 优化正式版与内测版共用引擎的首次启动，短暂检测超时会自动重试。
- 修复先更改引擎保存位置后无法导入引擎包的问题，正式版与内测版继续共用所选资源位置。
- 原站模型下载失败时提示检查网络或代理节点，已核实资源可直接切换到网盘下载。
- 修复更改模型文件夹后持续等待的问题，可直接复用已有模型目录；切换过程显示实际状态，失败后可重试。
- 改进外部 ComfyUI 模型库兼容，保留所选目录，并补齐 Qwen Image 2.1 必需的画布节点。
- 引擎设置提供下载和导入入口，下载完成后可直接拖入画布安装。
- 云端全景默认优先选择已配置的 Nano Banana 2.1，保留手动选择与清晰度设置。
- 修复设置中放大模型列表重叠，视频模型按 VOSR2、SeedVR2、Topaz 顺序显示。
- 重做配音节点与独立创作窗口，配音、声音克隆、配乐和音效使用紧凑输入区；选择音色即可试听原始样音，真实波形随播放进度显示。
- 声音库新增英语、日语、韩语和俄语男女声共16段开放授权样本，支持按语言筛选。
- 云端配音支持通义、MiniMax、OpenAI、Azure及兼容接口，按所选模型提供实际支持的音色、格式和参数。
- 音乐风格提供8段开放授权试听，可查看来源与署名，未提供样本的风格保留文字选择。
- 模型接口面板可直接启停已保存的云端连接，设置按钮准确打开对应接口。
- 模板包导入完成后短暂停留并平滑淡出，重新打开模板库不再显示上次的完成进度。
- 修复模型下载、卸载与设置子窗口的显示层级和焦点。
- 3D预览操作改为悬停显示；锁定后可直接拖动整个节点，解锁后旋转模型；下载菜单可选择GLB、FBX、3DS与OBJ。
- 3D全屏预览新增灯光亮度、方向、高度与冷暖调节，支持连续色板、HEX上色、恢复原色、复位视角、自动旋转和线框。
