# BBTV 0.1.19

- 图片高清新增 MiniMax H3 Image 细节增强，保留传统放大方式；提供通用提示词、根据当前图片优化、手动编辑和原文/优化后切换。
- 图片放大支持先按75%、50%或25%普通等比例缩小，再交给放大模型，显示输入与最终尺寸，保留原图。
- H3视频增加参考图比例复刻，按模型约束匹配接近源图的合法尺寸；二次采样展示独立阶段与实际进度。
- H3 Image 参数开放 CFG 与重绘强度 denoise，并完整传入实际采样。默认采样器 euler_ancestral、调度器 sgm_uniform；重置恢复推荐值，手动设置继续记忆。
- 视频人脸修复沿用原视频画幅，修复处理超过40秒被误判未提交，以及Windows进度文件短暂占用造成中断的问题。
- 面部与人物细节四视图新增纯净白底、暖灰棚拍、冷灰棚拍和深灰轮廓背景，保留身份、服装与四格角度。
- 视频放大保持原视频比例，取消后保留本地处理参数，调整与重新生成沿用原视频和本地模型。
- 主体替换编辑时隐藏原视频工具栏，关闭、取消或创建替换节点后恢复；参考图统一在输入区选择。
- H3 六段提示词将声景中的角色对白同步到画面描述，强化说话人和口型对应；新增原稿、实际提交字段、二采参数与复现资料。
- 增加H3 Image原图/结果滑动对比、视频人物替换三列展示和狗对白实测。新样本两句完整识别，严格发言时序及定量口型同步仍有局限，详情见[PRD4实测与复现](https://bbtv.ainivox.cn/review/prd4/)。

Windows安装包、官网及在线更新同步发布。安装包沿用未签名发行方式，真实签名状态为NotSigned。
