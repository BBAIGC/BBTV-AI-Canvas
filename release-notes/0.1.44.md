# BBTV 0.1.44

- 修复 Topaz 视频放大编码失败与目标尺寸偏差，模型处理后使用内置编码器输出，保留原帧率和音轨。
- GPU 可用时补帧优先使用 RIFE，复用模型与边界帧、减少重复上传和无用帧输出；明确选择的 CPU 光流保持不变。
- 多选视频新增同时播放、同时暂停，支持两个及以上视频对比并同步续播，隐私视频保持保护。
- 视频放大、补帧后复制水印版，沿用最后一个视频生成模型名称，复制或删除上游后仍保留来源。
- 本地模型启动增加独立 CUDA 兼容检查，区分驱动、运行时、架构与检查超时；诊断包补齐显卡、显存、驱动与 PyTorch/CUDA 信息。
- 包含0.1.42与0.1.43的删除取消与队列释放、批量运行、标注评论、兼容图片编辑模型、复刻侧边固定按钮，以及视频放大目标尺寸和处理设备选择修复。

已有项目、媒体、模型与接口设置保留。

安装器大小 175,440,276 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。

验证范围：Topaz真实本机GPU处理自建带音轨短片，2倍1472×2560、精确4K2208×3840及2944×5120三种输出均通过尺寸、帧数、帧率、时长及原音轨校验；模型推理与内置H264编码分离，避免NVENC高度限制及Topaz缺少libx264；完整分辨率1472×2560的24到60帧补帧以自建4帧短片实测：RIFE首轮8.037秒、再次6.540秒，CPU光流15.532秒；每种输出10帧，音轨与原片字节保留，未下载模型或取消用户任务；视频处理支持2、4、6、8、10倍及最长边/最短边目标；CPU、GPU和真实CPU卸载混合模式按可用后端展示，完整请求流程与真实CPU缩放至4K通过；多选视频同步播放、暂停、续播及卡顿重试的真实播放器验证4项通过，未选视频和隐私视频保持暂停；放大与补帧后的水印复制保留原视频生成模型；连续两次放大再补帧、复制导入与删除上游、旧图链恢复与环保护验证通过，未知导入视频保留中性来源；诊断保留Torch/CUDA初始化失败前的信息，区分CPU版Torch、架构不匹配、驱动查询失败与探测超时；导出诊断包排除设置文件并脱敏，真实Python探针与隔离故障fixture共7项通过；新装与旧未标记CPU默认使用已就绪GPU RIFE，用户显式CPU选择及已有CPU节点配方保持；实际控件/重开/队列重试3项通过；0.1.44最终安装包完整性及1554份源码、269份服务端输出、45份桌面文件一致性通过；实际编译包内多视频播放、水印生成来源与GPU补帧偏好3组通过，独立测试服务已停止。。

验收限制：真实GPU验证使用隔离自建短片，不代表所有素材、长片或高倍数的速度与画质；RIFE首轮未重置显卡模型驻留，不能称为严格冷启动；诊断失败路径主要通过隔离NVIDIA/Torch故障fixture验证，未在用户电脑上人为破坏驱动或CUDA环境；仅发布画布；独立剪辑0.2.5保持原包，未新增付费云端生成；模型同步与历史构建留存按用户要求后置；对方RTX2080电脑的驱动与Torch/CUDA问题本轮只增强诊断和兼容性提示，未远程修改或更新其显卡驱动；需要安装新版后重新导出诊断，才能针对该电脑确认根因及后续修复。。
