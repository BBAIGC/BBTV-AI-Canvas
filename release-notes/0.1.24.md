# BBTV 0.1.24 更新说明

2026-11-13。本版本修复复制成品图片后误覆盖参考原图的问题，并包含 0.1.22 与 0.1.23 的图片创作及模型下载修复。

- 从其他画布复制、粘贴、复制节点或导入的成品图片，会作为当前画布的新参考原图使用。点击“生成”创建连接的新结果，保留原图与外接参考，不会直接覆盖复制进来的图片。
- 只有当前节点自己的执行记录才启用“重新生成”。原节点真正生成的结果继续原位重跑；取消后保留可用图片和生成身份，提交期间的“+1”仍沿用原有参考。
- 反推和提示词优化新增“MiniMax H3 Image”目标风格，使用图片自然语言描述与实际参考绑定语义，避免误用视频六段式。反推、优化和前置词设置共用目标风格；自动默认匹配当前生图模型，并保留用户已保存的手选配置。
- 提示词“@”和替换引用只列出当前已连接素材及有效主图，不混入整张画布上的无关图片，也不会自动为未连接素材建线。
- 普通图片“重新生成”保留原图、半透明暗层和生成进度，完成后在同一节点替换图片，保留原有模糊到清晰过渡。
- “+1”使用原参考创建并列结果，保留连线与提示词引用；连续生成不会逐次把之前的结果图加成新参考。
- 图片生成期间可切换下一张的本地、云端及具体模型，再立即“+1”。已提交任务继续使用原设置，当前任务未结束时不能重复在同一节点重新生成。
- 直接高清放大面板缺少模型时，提示旁提供“下载模型”，可查看对应网盘位置、文件名和安装目录；支持自动下载的模型保留现有自动下载入口。
- 更新安装不再被未结束的历史任务记录永久阻断；确认任务影响后保存全部画布再安装，错误提示去除内部通信前缀。

验证覆盖真实复制与粘贴存储、生成动作、参考连线及已打包程序界面。生成请求使用拦截与模拟结果，未新增实际模型生成质量测试。

Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。已有模型、项目和素材继续保留，无需重新下载模型权重。
