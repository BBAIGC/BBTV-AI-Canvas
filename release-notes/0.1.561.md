# BBTV 0.1.561

- 本次为 0.1.56 的补丁更新（0.1.561），修复相关 Bug。
- 支持识别并导入 Qwen Image 2.1 的 BF16、INT8 等原生权重变体，使用对应加载方式，保留现有 GGUF 方案。
- 拖入本机文件或文件夹时统一显示全窗口提示，松开后再识别；无法识别、路径读取失败或正在处理时显示明确反馈。
- 支持单独拖入模型配置、分词器等配套文件，也可导入仅包含配套文件的子目录。
- 完善 VOSR2 配套检测，缺少文件时在生成前提示，并提供对应资源入口。
- 修复旧模型目录失效后模型列表读取失败的问题，资源位置不可用时显示清晰提示并保留原配置。
- 导入前检查整批资源所需空间，容量不足时可更改保存位置或取消，检查通过后继续导入。
- 更新下载增加网盘入口，下载较慢时可选择网盘；修复不同安装范围遗留重复桌面快捷方式的问题。
- 修复复制图片节点或继承生成偏好后无法切换文生图的问题，保留专用图片工具的参考图要求。

已有项目、媒体、模型与接口设置保留。

安装器大小 209,314,180 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。

验证范围：正式安装包在独立环境启动，引导配置、窗口切换和返回画布通过检查；拖入资源、配套文件、整批空间检查和更新入口通过针对性验证；Qwen Image 2.1原生精度变体及图片生成模式切换完成回归；安装器归档、源码与运行文件逐项校验通过。

验收限制：本轮未重新运行完整GPU生成；不同精度模型仍需对应配套与足够硬件资源。
