# BBTV 0.1.55

- 模板库导入时在顶部显示当前阶段、进度条与百分比，导入完成可直接刷新素材。
- MiniMax H3 多视角与 Qwen 2.1 多角度分别提供真实示例；单参考编辑节点插入时即按原图画幅展示，Qwen 标准与 Turbo 切换时分别使用对应采样步数。
- 更新 Qwen 单图、双图和 MOSS 单图编辑的前后对比。模板包 r9 包含 58 个模板所需的参考图、视频与预览。
- 3D 模型支持节点内与全屏拖动旋转，并可导出 GLB、FBX、3DS 和 OBJ；修复部分便携引擎在生成前无法分离主体的问题。
- 视频放大列表和模型设置统一展示可用方案，缺少 Topaz Proteus v3 等配套时可查看安装步骤并刷新识别。
- 「视频主体替换」模板展示从参考原图、角色提取和多视图到成片的完整流程，换接自己的原视频或角色图后可直接替换，默认处理整段视频。
- 「多图参考视频」模板更新为 1088×1440 成片预览。
- 模型设置支持单独卸载或全部卸载，可查看清理范围和进度；全部卸载前需要两次确认。
- 更新「Krea2 机械雕刻」模板，使用白衣人物与白色机甲的示例图，并预填生成该图的提示词、种子和四组 LoRA 强度。
- 修复助手重启与项目恢复后的布局异常，统一加载助手基础样式。
- Krea品牌图标改用清晰矢量，模板全景新增球形标识、抓手光标和首次拖动引导。
- 模板素材包清除图片与视频中的隐藏生成信息，模板结构与执行流程随软件提供。
- 新增图生3D与文生3D，支持单张或多视角参考、本地 Hunyuan3D、交互预览与 GLB 下载；自动分离主体背景，3D模型扩展包按需准备。
- 支持自行配置 Meshy、Tripo、Rodin 官方3D接口及 Comfy API，默认使用本地模型。
- 支持将自有 LoRA 与同名预览图一起拖入画布，自动识别、配对导入并刷新；无法确定类型时可直接选择 LoRA 或大模型。
- 模板库支持图片与视频前后滑动对比、球形全景直接查看、多角度组合预览；重新打开时恢复全部筛选，模型菜单显示对应图标。
- 更新人物换装、多图编辑、建筑截图转写实、古风滤镜与全景示例，模板参考图使用可识别的引用，缺少新资源时提示更新模板包。
- LoRA库支持立即刷新手动添加的模型、完整名称和随鼠标移动的大图预览；复制结果会保留该结果实际使用的 LoRA。
- 全景球形视口默认竖向3:4，生成及超分期间保持展示比例，原始2:1全景仍可随时查看与保存。
- 修复配音运行时输入框遮挡节点，生成等待期间持续显示运行反馈，H3首次加载和低显存准备阶段使用更清晰的提示。
- 声音库扩大面板并统一深色样式，补齐弹出、悬停、选中及试听播放反馈，新增8种可试听、可用于配音的自然人声。
- 单声音和双声音模板预填人物参考、台词及音色，修复配音生成、重试和角色音色绑定，双声对白不一致时自动校正。
- 补齐单声音、双声音、人物替换和主体替换的真实视频预览，并同步更新参考素材与生成参数。
- 正式版与内测版共用模板素材，自动兼容已导入资源；更新只补充变化项，保留旧素材和已有画布引用。
- 修复内测版从托盘重新启动后未找到已配置本地引擎的问题。
- 优化 H3 Image 相同参考图、提示词和尺寸下的连续生成，复用已完成的输入编码，保留原始清晰度、采样步数和解码流程。
- 本地图片生成进度覆盖模型加载、输入编码、采样、解码与保存，等待首步期间持续显示运行状态。
- LoRA 选择支持模型分类、卡片与列表预览及个人参数预设；下载弹窗直接显示实时进度、当前文件和暂停继续操作。
- 新增分类模板库，采用紧凑窗口和桌面五列预览；缺少素材或素材有更新时提供下载引导，支持直接拖入 ZIP、可编辑节点和可跳过的操作引导，打开后才按需加载图片与视频预览。
- 模板增加风格 LoRA、室内白模转写实和本地语言模型入口，补齐品牌图标，支持双击卡片使用；预览素材与对应参考图、提示词和参数一起更新。
- 恢复独立 MOSS Image 图片编辑入口，配套编辑 LoRA，并按官方流程处理参考图、采样及输出比例；原有文生图入口保留。
- 生成参数支持先清空再输入，保留上下微调，鼠标拖选和滚轮不再意外修改数值；步数、CFG、LoRA、采样器和调度器支持撤销重做。
- 画布设置分为通用、生成、外观、Agent和快捷键；开启“记住模型生成参数”后，同模型设置可跨节点、画布和重启保留，并可恢复模型默认。
- 正式版与内测版保留独立入口和项目列表；两版可互相复制节点及其媒体，安装正式版后继续保留内测版；内测覆盖安装确认后自动关闭对应旧程序。
- H3 Image 新增可选 LoRA 加载及独立 NSFW 开关，补充 Seedream 写实风格和亚洲人像下载入口；默认不下载、不启用。
- 项目资产新增随鼠标移动的大图预览、网格与列表切换、缩略图大小调节和右键操作；改善角色库间距、引用文字及切换反馈。
- 生成历史与队列优化文字、按钮、选中和运行状态，列表使用可用高度；历史全图预览去除顶部遮挡，缩略图支持悬停放大。
- 宫格切分支持拖动分割线、输入像素位置和撤销重做，输出按调整后的区域裁切；资产图移到常用工具栏，统一九宫格图标。
- 修正多角度球形预览在侧面和背面时的俯仰显示；全景预览比例明确标示横向、竖向和方形，参数窗口增加可用高度。
- 模型接口刷新会重新检测已启用的云端连接，分别显示检测中、连通及异常结果，并保留失败详情。
- 资源占用默认常驻工具栏，用户收起后保留选择；模型接口入口改用简洁图标。
- 应用信息页重新排版，点击当前版本可检查更新，有新版时显示红点；修复助手调整宽度时反复闪动的问题。
- 合并模型与引擎设置，按引擎、模型和安装方式分类；读取配置时保留布局位置，电脑配置补充显存容量、内存代际与配置频率。
- 模型列表按功能分类、分页展示，网盘与原站入口固定对齐；下载支持暂停续传，主页与画布可查看下载、识别及导入进度。

- 图片复制保留透明 PNG 的 Alpha，补齐图片与文件复制的透明剪贴板格式。
