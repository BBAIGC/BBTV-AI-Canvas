# BBTV 0.1.21

- 软件更新改为独立弹窗，突出新版本、立即更新和官网入口；下载完成后提示安装，也可稍后继续安装。
- 模型准备逐项显示主模型、文本编码器、VAE、LoRA 的准确网盘位置与文件名，支持单文件复制和智能体安装提示词；本地模型列表显示更多行。
- 网盘与 NAS 的 140 个模型资源按模型目录重新归类，共享依赖只保留一份；新增 48 套按模型安装清单，兼容旧版资源目录导入。
- 恢复普通图片节点的文生图、图生图和模型切换；高清处理在确认后创建任务，补充 H3 Image 分类细节预设与精确缩放；H3 Image 移至模型列表前排并以金色标注“最新”。
- 选中图片作为参考1显示缩略图并支持 @ 引用，上游参考按顺序排列；H3 Image 使用原生图片标记绑定主图和附加参考，修复参考提示无法正确对应的问题。
- 修复图片重复粘贴、删除后撤销恢复和大图剪贴板兼容，完善大图预览信息、按钮反馈和通知位置。
- 简化视频主体替换与换脸操作，明确原视频和参考图，完善时间范围、分段与替换参数；生成节点的阶段标题与百分比同一行显示，修正排队计时和预计剩余时间。
- 改善模型卸载、缓存清理与引擎启动反馈，调整小窗口布局，并优化大量节点画布的操作响应。
- 数值输入支持直接拖动调值，保留键盘精确输入；采样器和调度器统一放在参数末尾。
- 四视图“保留配饰”严格跟随原图，没有的配饰不再添加；去除配饰继续保留服装细节。
- 大图裁剪使用轻量预览避免超出浏览器画布尺寸，按原图像素输出裁剪结果；同画布记忆模型选择，多角度默认 H3 Image，单独记忆手选模型并先创建带角度参数摘要的待确认节点，确认后再生成。

沿用现有模型和项目，无需重新下载模型权重。生成效果取决于模型、素材和参数。Windows 发行包真实签名状态为 NotSigned。
