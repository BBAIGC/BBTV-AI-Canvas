# BBTV 0.1.16

发布日期：2026 年 11 月 11 日

## 图片预览与模型切换

- 移除图片大图预览顶部的整行黑色遮罩；预览期间隐藏画布拖动区，关闭、缩放、拖动和 Esc 退出保持可用。
- 图片、视频节点在空闲时可切换本地或云端以及具体模型；不再将 Agent 对话的模型规则应用到生成节点。
- Agent 已开始对话的模型规则保持独立，历史结果继续记录实际生成模型。
- 人物多视图明确每格朝向、取景范围与同一人物约束；生成质量仍受所选图片编辑模型与参考素材影响。

本版修复上述问题，不表示原 PRD 的外机安装、严格换角及完整主体替换质量全部验收通过。

本地功能继续永久免费；安装包、模型依赖与硬件准备见[主页](../README.md)和[模型文档](../MODELS.md)。
