# BBTV 0.1.33

- 修复 MiniMax H3 视频无法生成：解决制作设置残留旧时长导致的“视频剧本版本、时长或任务类型无效”，已有视频节点可直接重试，修改秒数或帧数同步生效。
- 本机模型按队列逐个执行，反推、生图与视频生成等待前一个本机任务完成，避免同时占用资源。
- 图片复刻一键开始：立即建立反推文本和生图节点，先反推、再自动生成，状态与普通任务一致；修正首次反推的上下文容量。
- 复刻面板沿用图层分离的控件风格，修复图片下方输入区和工具面板遮住原图的问题。
- 新增模型更新提示，可查看模型用途、所需文件与百度网盘下载位置。
- 停止 Agent 控制只结束当前会话，保留 MCP 启用设置；任务完成后释放控制，活动操作保持连续。
- BBTV剪辑 0.2.2 修复窗口四边与四角缩放，接入官方在线更新提醒、下载校验及保存后安装。
