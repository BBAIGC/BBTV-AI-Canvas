# BBTV 0.1.53

- 修复批量任务失败后反复报错、恢复上一结果或重新进入画布后自动重新提交的问题；失败任务只在主动重试时重新运行。
- 修复剪辑同步画布后关闭仍重复保存、重复导出和等待过久的问题；未修改直接关闭，修改保存并同步成功后自动关闭。
- 再次编辑剪辑结果支持覆盖原剪辑或另存一条；打开工程不新增结果节点，覆盖保留原节点并显示编辑次数。
- 主体替换使用原视频与参考人物整体融合生成，修复沿原人物轮廓回贴导致的描边和破洞；人物、产品和面部预设自动绑定素材，框选用于定位替换目标。
- 生成输入和图片视频工具支持统一放在左、右或下方；下方面板所有参数、开关和创建操作合并为一行。
- 安装、更新或重装后首次进入显示品牌开幕；点击进入后，英文淡出并衔接项目主页入场。
- 项目主页新增总隐私开关与单项目封面开关，支持磨砂隐藏、单独显示和自动记忆。
- 设置新增资源保存位置及安全迁移，后续导入沿用新目录；可打开图片视频目录，节点可识别资源删除、暂不可用与恢复。
- 配套 BBTV剪辑升级至0.2.6，需同时更新画布与剪辑器。

已有项目、媒体、模型与接口设置保留。

安装器大小 175,835,148 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。
