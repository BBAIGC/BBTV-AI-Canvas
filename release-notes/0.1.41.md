# BBTV 0.1.41

- 图片编辑改为画布内工具条，统一标注、评论、移除背景、去水印和擦除；标注与评论发送为相连参考图片，可继续图生图。
- 评论支持多行输入、编号气泡及图上和底部重新编辑；擦除增加左侧笔宽滑杆和尺寸预览，支持撤回重做。
- 去水印默认启用文字与白色水印，开关记住选择，提示词可折叠；去水印和移除背景确认发送后直接生成，保留原图。
- 修复 Krea2 二采解码缺少必填参数；首采与二采 LoRA 独立生效，第二轮步数、采样器和 LoRA 可分别调整。
- 修复云端图片继承本地反推配置后误入本机队列，云端按并发上限独立提交。
- 扩大 LoRA 搜索列表，支持连续添加；选择期间和关闭列表后均保留参数面板。
- 视频切换节点后单击即可播放，收紧控件并完整显示当前和总时长，优化倍速菜单；隐私保护覆盖播放控件并暂停视频。
- 更新窗口仅显示当前版本，更多版本使用独立大视图，关闭后返回更新窗口；模型目录移到清理区域上方并支持打开。
- 安装向导左侧图片随页面高度拉伸，修复扩大窗口后的底部留白。

已有项目、媒体、模型与接口设置保留。

安装器大小 175,423,946 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。
