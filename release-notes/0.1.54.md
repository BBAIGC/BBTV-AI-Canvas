# BBTV 0.1.54

- 新增长视频文生视频、图生视频，按设备和清晰度分段处理，显示整条视频的进度与预计时间，完成后合成为带音轨的视频。
- 新增视频人物白模、时序深度及双输出，结果可继续用作视频参考或深度控制，保留原视频与已完成结果。
- 360°全景新增本地 Qwen Image 2.1 路线，自动带入全景 LoRA 和 2:1 画幅，可选 1K、2K、4K，默认 2K，支持填写补充要求；原有云端路线继续保留。
- 图片“更多”菜单新增“转为全景图”，导入的全景展开图可直接球面浏览，并切回普通图片查看。
- 新增区域录屏：框选后持续录制，显示选区、计时、暂停、继续和停止控件，停止后选择保存位置；暂停时段不计入成片。
- 3D 导演台新增 8 类骨骼人物、20 组姿势及实体相机模型，人物关节可调整，场景预览与输出沿用当前设置。
- 导演台新增多机位、圆弧与贝塞尔轨迹、手绘路径、独立轨道和平滑阻尼，支持截图及时间轴视频保存回画布。
- 图片生成数量支持直接输入 1 至 16 张，分别创建相连结果节点，并按本地、云端队列并发调度。
- 新增使用当前图片的 Nano Banana 云端高清增强入口，可从已有图片继续处理。
- 重整 3D 导演台布局与图标，支持撤回重做、整体拖动轨迹及相机锁定人物锚点，保存、回放和输出使用相同轨迹设置。
- 多角度与打光更新三维预览；选择标准 Qwen Image 2.1 时默认启用机位 LoRA，可手动关闭或添加其他 LoRA，保留 H3 推荐及用户模型选择。
- 标准 Qwen Image 2.1 的“室内设计”默认使用光影融合 LoRA、强度 0.7；切回“通用”撤下自动项，手动选择、关闭与强度设置继续保留。
- 室内提示词生成器的补充要求默认留空，可从参考图选择本地或云端模型反推，保留用户手动填写内容。
- 补齐 Nano Banana 2.1／Gemini 图片模型的模板映射，按当前模型选择图片反推与优化模板，并保留手选模板、语言和已保存设置。
- 图片标注与评论编辑优先使用标准 Qwen Image 2.1，仍可按可用模型选择其他本地或云端图片编辑路线。
- 云端自动选择支持全局及各接口的经济、速度排序和失败回退，设置按选择记忆。
- 简化云端自动选择入口，经济、速度策略放入设置；创作助手模型按本地、云端和接口分类，接口删空后直接进入供应商选择。
- 统一图片工具条、多角度与打光入口，补齐 29 个工具预览；调整选中边框、文字编辑空间和节点下方预设横排。
- 视频参考显示缩略图并继承原视频比例，比例复刻支持视频；图片与视频分别记忆模型，云端目录暂不可用时保留已选视频模型。
- 整理去水印节点的重复参考图和提示词，先创建待确认节点，再由用户点击生成；“更多”菜单移除重复的去水印、去背景入口。
- 人物替换增加发型来源、服装来源控制，保留手动提示词、参数保存和撤回重做。
- 主体替换按实际分段显示编码、采样步数和解码状态，总进度与预计剩余时间覆盖全部分段及最终合成。
- 补齐主体替换结果的范围、时段、参数和原声开关，创建操作集中在右侧；底栏保持单行，提示词与参数窗不再互相遮挡。
- 创作助手打开时仍可显示画布节点的生成输入与参数；图片、视频输入区去掉重复进度和计时，统一在节点及任务队列查看。
- Standard、Turbo 缺少配套时可直接打开下载引导；诊断包补充 H3 模型路径、配套文件、节点注册及兼容性信息，引擎断线时显示配套尚未核实。
- 人脸替换增加运行依赖预检，区分模型文件已安装和实际运行依赖可用状态。
- 开幕字标适配大屏显示，每次启动播放一次并保留设置开关；托盘增加“重新启动”，退出前先保存画布。
- 调整 MCP 鼠标提示与画布控制边光，让当前控制状态和操作反馈更清楚。
- 移除画布顶部“画布／故事板”切换及独立故事板预览弹窗，继续保留创作助手、分镜节点和分组操作。
- 修正室内预设把庭院、露台等开放场景强行按封闭室内处理的问题，短提示词沿用原图室内、室外及半室外关系。
- 修复启动声音在窗口显示前播完的问题，品牌弹入动画等待窗口与图片准备后同步播放。
- 修复导演台多对象旋转时的悬停拖拽冲突和退出时主进程报错，补齐三轴、平面手柄、Shift 多选和 Delete 编辑防误删。
- 修复全景草稿反复弹出模型、清晰度选择和模型标签错误；独立记忆接口、模型与清晰度，标题可拖动，非球面尺寸结果保留原图并提示。
- 修复已有全景图使用 VOSR2 放大时提示缺少参考图的问题，直接使用当前选中的展开图，并保留全景浏览标记。
- 新建人物替换使用标准配方，调整原生视频参考步数时不再自动切换加速模型；提前读取已确认的模型状态，减少首次打开时参数与按钮闪变。
- 修复主体替换重复创建结果节点和长片时长显示，接续完成后保留一个结果节点及原视频音轨。
- 修正面部视图强制吐舌的问题，保留原图表情；卡通多视图沿用主体类别和画风，面部取景保留头部与上胸的连接，Qwen 四视图补充正面约束。
- 多选视频播放时收起蓝色遮罩，暂停或播放结束后恢复，选中范围继续显示外扩虚线框。
- 修复剪辑组件更新弹窗的版本显示、安装等待和关闭操作的画布侧交接，沿用现有剪辑器版本。
- 完善测试版转同版本正式版的更新提醒、下载校验及安装状态恢复，并继续拒绝旧版本和测试渠道清单。
