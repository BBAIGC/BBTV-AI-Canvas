# BBTV 0.1.17

发布日期：2026 年 11 月 12 日

- 修复超过20MB本地生成图片的接收限制；支持6K、8K保存、预览与导出。
- MiniMax H3 Image 可手动选择采样器、调度器；重生成暗色遮罩与渐清过渡、实色会话菜单改善可读性。
- 剪辑支持非模态小窗、拖动和边角缩放；处理中继续编辑轨道与素材，并预览已完成的放大帧。
- 新增 SeedVR2 官方视频时序放大，以及调用本机已授权 Topaz Proteus 的可选路线；Topaz 商业模型不随 BBTV 分发。
- 修复重复剧本导致声音引用、对白标签丢失的问题；台词回读不符时可用本地音色克隆重配，保留原始生成片。
- 快捷音频与媒体处理默认创建画布任务；主体替换和重拍输入位于节点下方，补充声音库菜单入口。
- 增加角色身份、声音、台词时间窗及兼容采样配方；连续长视频保存 latent、Take 与恢复会话。
- 分镜累计时间码随时长与顺序变化自动重算；补充导演台关节动作、场景资源、逐模型控制及专用机位模型。

台词正确不代表口型或音色完全通过；严格机位、复杂多人替换和另一台新 Windows 的验收仍按实际证据逐项记录。
