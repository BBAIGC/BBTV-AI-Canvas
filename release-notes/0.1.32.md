# BBTV 0.1.32

- 自动字幕复用 BBTV 语音转写服务，新增多语言模型下载入口；画布字幕入口自动定位、识别并按片段时间入轨，预览字幕支持双击直接编辑。
- 剪辑器融合视频放大、插帧补帧、去除硬字幕和人声伴奏分离，提供模型参数、单帧对比预览、实际进度与取消。
- 预览新增监听音量浮层，修复自定义比例显示和播放头整条拖动；SAM 抠图和多帧提示词反推可直接在画布中操作。
- 剪辑 MCP 增加一键复制完整连接配置、九档操作速度和实际调用反馈，支持字幕及视频模型工具。
- 剪辑窗口首次居中，关闭前询问保存；先保存本地工程，画布任务收到同步确认后退出。
- 更新弹窗防止点击遮罩误关，后台下载完成主动提醒安装；普通媒体拖入直接创建加载节点，资源包使用专用导入遮罩。

已有项目、媒体、模型与接口设置保留，BBTV剪辑按需独立安装。

安装器大小 175,346,453 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。

验证范围：真实语音字幕及时间轴映射、VOSR2 单帧放大、视频与音频人声伴奏分离、去字幕与48fps补帧、原生MCP和关闭保存回执、生产运行时大于10MB文件上传。原生窗口启动与居中已检查；未进行本版逐控件鼠标视觉验收，其他放大模型未逐个推理。
