# BBTV 0.1.27

- MCP 顶部蓝色控制条显示实际智能体，支持调速与停止；新任务默认新建画布，保留用户当前项目。
- 新增 bbtv_configure_api，在真实可见窗口中配置用户提供的接口并读取模型，不回显密钥。
- 官网增加醒目 MCP 导航和 AI 操作画布介绍，GitHub 首页前置 HTTP、stdio 接入与通用 Skill 下载。
- 图片生成显示真实挂载、编码、初始化、采样、解码与保存阶段；历史估算明确标注，修复中途变慢后一直校准剩余时间。
- 完善取消、队列停止、多选停止和图片编辑预设，保留原图及任务参数。
- MCP 操作速度提供九档：极速、很快、快速、流畅、自然、稍慢、慢速、演示、逐步。调整后立即生效，保留正在执行的任务；长批次按速度和步数分配等待时间。
- 新增独立 MCP 设置。智能体可在真实可见画布中创建与编辑节点、连线、导入本机素材、检查图片结果并操作生成队列，界面同步显示操作光标。
- 标注增加本地与云端原生图片编辑：填写修改要求后先准备原图、标注参考和可选圈选蒙版，确认后再生成，保留原图。
- 连接图片参考后自动使用图生图，保留明确手选模式；修复重新生成和“+1”混入自身结果或丢失有效参考的问题。
- 调整图像反推和复制比例面板；去水印先准备可编辑结果，图片复刻按清理、反推、生成依次执行。

已有项目、媒体、模型与接口设置保留。安装器大小 175,280,659 字节。
