# BBTV 0.1.30

- 修复已安装推理引擎缺少 ComfyUI API 源码造成的启动失败；匹配引擎版本后补齐必要源码，保留已有模型和用户数据。
- 启动失败原生窗口和首次引导提供日志位置、打开日志、导出诊断与重试入口。
- BBTV 剪辑支持独立启动、导入视频和本机工程，并可连接主画布同步结果；改进手动安装及自定义路径发现。
- 剪辑保留独立字幕轨和无字幕视频源，补帧、放大、剪辑后仍可修改字幕，结果节点显示处理进度。
- H3 加速档位与真实采样配方一致，制作设置使用紧凑下拉；二次采样仅对有可恢复首轮缓存的本节点新结果开放。
- 新增 MCP 画布重命名，改进自定义下拉框、模型连接选择和可见设置操作；控制条与实际顶部工具栏对齐。
- 修复云端自动模型选择与反推任务重生成；模型清理需两次确认并在完整文件边界停止。

已有项目、媒体、模型与接口设置保留。独立剪辑端按需安装。

安装器大小 175,333,453 字节。Windows 安装包真实签名状态为 **NotSigned**，不宣称已签名。

验证范围：工作流、协议、界面、CPU媒体处理与本机启动；本轮未新增 GPU 成片质量验收。


BBTV 剪辑 0.1.1 对应源代码：[源码 ZIP](https://bbtv.ainivox.cn/editor/source/BBTV-Editor-0.1.1-source.zip)。
