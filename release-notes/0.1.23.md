# BBTV 0.1.23 更新说明

2026-11-13。本版本包含已完成验证的图片生成与模型下载修复。

本版本包含此前尚未正式发布的 0.1.22 修复，以及本轮高清模型下载入口优化。

- 提示词 `@` 与替换引用只列出当前已连接的参考素材及有效的当前主图，不再混入整张画布上的无关图片，也不会因选择引用自动连接其他素材。
- 恢复普通图片“重新生成”的原位行为：保留当前图片，叠加半透明暗层和生成进度，完成后替换同一节点中的图片，保留既有从模糊到清晰的过渡。
- `+1` 使用当前生成的参考图创建并列结果，保留连线、顺序和提示词引用；连续生成不会把前面的结果图逐次追加成新的参考图。
- 图片生成期间可以切换下一张使用的本地、云端及具体模型，再立即 `+1`。已提交的任务继续使用原设置；当前任务未结束时不能在同一节点重复启动“重新生成”。
- 更新安装遇到未结束的历史任务记录时，显示任务影响并允许确认安装。安装前保存全部画布；更新错误显示实际原因，去除内部通信前缀。
- 直接高清放大面板缺少模型时，提示旁提供“下载模型”，直接打开对应模型的准备引导。VOSR2 清单列出 6 个所需文件，逐项提供网盘路径、文件名和安装目录；支持自动下载的模型保留现有自动下载入口。

本地真实程序验收覆盖原位重新生成、参考连线、运行中模型选择和高清下载引导。界面测试的生成请求全部拦截并使用模拟结果，未额外调用模型或收费接口；这些验证不代表新增的实际生成质量测试。

本轮安装包真实签名状态为 **NotSigned**，不宣称已签名。已有模型、项目和素材可继续使用，无需重新下载模型权重。
